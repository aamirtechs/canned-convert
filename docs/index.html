Free open source tool

canned-convert

Convert macros and canned responses between helpdesk formats offline, with placeholders translated through an editable mapping file and a report of anything that could not be mapped.

View source on GitHub

What it does

  • Zendesk macros to Freshdesk canned responses, in JSON or CSV, and Freshdesk canned responses back to Zendesk macros
  • Placeholder translation through an editable placeholders.json mapping file covering 17 shared concepts
  • A conversion report lists every unmapped placeholder with a reason, so a human can finish the job with a complete list
  • Placeholders with no equivalent in the target platform are left as-is and documented, never silently dropped
  • Optional plain text mode strips HTML tags from bodies while converting

Install and usage

Requires Node.js 20 or later. There are no dependencies to install.

git clone https://github.com/aamirtechs/canned-convert.git
cd canned-convert
node src/cli.js --input examples/zendesk-macros.json --from zendesk --to freshdesk --output freshdesk.json --report report.md

Add --format csv for CSV output, reverse the direction with --from freshdesk --to zendesk, or pass --mapping your-file.json to use your own copy of the mapping table.
