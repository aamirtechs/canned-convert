Free open source tool

canned-convert

Convert macros and canned responses between helpdesk formats offline, with placeholders translated through an editable mapping file and a report of anything that could not be mapped.

View source on GitHub

Use it in your browser

Runs fully in your browser, files never leave your device. Drop a macros or canned responses JSON export below, or paste its contents. Placeholders are translated with the shipped placeholders.json mapping, bundled into this page. Version 1 converts Zendesk to Freshdesk and Freshdesk to Zendesk, matching the CLI. Intercom and Chatwoot are seeded as good first issues in the repo and are not converted yet.

You can also drag and drop the file anywhere on this panel.
